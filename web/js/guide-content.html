一、这是什么

本地优先的 AI 文献管理桌面程序：导入 / 下载论文、AI 精读、全库问答、方法与参数库、复习卡片、Word 引文插件。所有文献、笔记、PDF 都保存在你自己的电脑上。

二、安装 / 升级

  1. 双击 NPL-Setup.exe，选择安装目录，完成会自动启动。
  2. SmartScreen 提示时点「更多信息」→「仍要运行」（未购买代码签名，可用 SHA256SUMS.txt 校验）。
  3. 静默安装：NPL-Setup.exe --silent --dir "D:\Apps\NPL"，可加 --no-launch。
  4. 便携版：解压 NPL-*-portable.zip，双击 exe，数据在 exe 同目录 data\。
  5. 升级安装会自动识别并关闭正在运行的 NPL（关不掉会强制结束；仍失败会提示你手动从托盘退出）。已打开的 Word 不会自动关，升级后请重启一次 Word。

三、第一次使用

  1. 打开「设置」，填任意 OpenAI 兼容 API：
    DeepSeek https://api.deepseek.com/v1 · 模型 deepseek-chat
    OpenAI https://api.openai.com/v1 · 模型 gpt-4o-mini
    通义千问 https://dashscope.aliyuncs.com/compatible-mode/v1 · 模型 qwen-plus
    本地 Ollama http://127.0.0.1:11434/v1 · 模型 qwen2.5:14b
  2. 填 API Key，保存后点「测试连接」。
  3. 到「我的研究画像」写清方向和在做的项目，新论文会分析与你的关联。
  4. 往「导入 / 添加」拖 PDF，或粘贴 DOI / arXiv / 网址，或去「发现论文」检索。
  5. 从 Zotero / Obsidian 导入的条目没 PDF 时，会自动尝试补齐；也可点文献库右上角「补齐 PDF」。

四、导入文献

  • 拖入 PDF：自动读标题、作者、DOI，并按 DOI 补卷期页等信息。
  • DOI / arXiv / 网址粘贴导入。
  • 批量导入：EndNote XML、RIS、BibTeX、Zotero RDF / CSV；按 DOI、arXiv ID、归一化标题判重，命中则补空字段和缺失 PDF。
  • 浏览器插件一键保存（见「浏览器插件」一节）。
  • 发现论文：用中文描述研究主题，AI 返回候选论文，可入库或忽略。
  • 剪贴板监听：复制 DOI / arXiv 链接 / 像论文题目的文字，程序自动提示。
  • 参考文献外扩：列出某篇论文的参考文献 / 引用它的文献，可批量入库并补 PDF。

五、文献库

  • 左侧分类支持三级：先列第一级，点进去才展开下一级；选中父级会筛出整棵子树。
  • 列表所有列可拖动调宽；缺 PDF 的条目可直接筛出。
  • 右键「编辑信息」改标题、作者、年份、期刊，以及卷 / 期 / 页码。
  • 老条目缺卷期页：设置 → 数据与存储 →「补齐卷期页」，按 DOI 批量补（只补空值）。
  • 回收站可恢复误删；备份 / 还原入口也在设置页。
  • 「分类助手」可只整理未分类，或对所有论文重新分类（执行前确认，可选择是否把 PDF 一起移到新分类目录），进度在任务中心。

六、AI 功能

  • 单篇精读：摘要、关键点、方法、结论，可追问。
  • 全库问答 / 知识库：基于你的库回答，并给出引用来源。
  • 阅读器：划词翻译 / 解释、批注、章节识别、本页 / 本节 / 批注 AI 材料。
  • 方法 / 参数库（左侧栏）：抽方法、实验参数、材料、设备；可搜索、按状态筛选、单篇或全部提取。
  • 复习卡片（左侧栏）：把论文变成「可迁移知识卡」——通用原理 / 取舍 / 适用边界，离开这篇论文也成立；支持今日待复习、按 SM-2 评分（1 放弃 / 2 困难 / 3 一般 / 4 简单）。
  • 任务中心：精读、PDF 抓取、方法提取、卡片生成、分类整理都是批次任务，显示进度、成功 / 失败数、失败原因，可「仅重试本批失败项」，重开程序也能看到历史。

七、Word 插件（插入引文 / 参考文献）

安装器把模板装到 Word 的 STARTUP 目录，Word 会出现「NPL」功能区标签。装完 / 升级后请重启一次 Word。

功能区按钮

  • 插入引文：打开独立的「添加引注」网页窗口。左侧分类树（可展开 / 收起，括号里是含子类的篇数）、顶部搜索、右侧条目表（标题 / 作者 / 年份 / 期刊，白 / 浅绿交替）；滚轮正常滚动；Ctrl / Shift 多选；双击某行直接插入；Enter 插入；Esc 取消。选完点「插入引文」窗口关闭并自动插入、重排编号；点「取消」或关窗口，Word 立刻停止等待。
  • 插入 / 更新参考文献：第一次放到文末；之后点它或「刷新」原地更新，不会重复追加。
  • 刷新：库里改了信息或手动移动了引文位置，按文档顺序重排编号。
  • 引文格式：可搜索的格式列表，内置 APA / MLA / Chicago / IEEE / Nature / GB-T 7714，以及设置页里生成或导入的格式；当前格式标「← 当前」，数字型标「（数字型）」。
  • 端口：默认 8765；测试连接；使用说明。

编号规则（数字型格式）

  • 单篇 [1]，两篇 [1,2]，连续三篇及以上折叠成 [1-3]；不连续如 [1,2,5]。
  • 编号永远按文档先后顺序；在已有引文前面插入，后面的自动顺延（原来 [1-6]，前面插两篇后变 [1,2] [3-8]），插入后自动刷新。
  • 引文以书签保存：不要手动删引文文字；删了重新插一次即可。

模板位置：%APPDATA%\Microsoft\Word\STARTUP\PaperWhaleMacros.dotm。若 Word 提示「编译错误」，关掉报错窗口 → 那个文档不保存关闭 → 重启 Word；仍不行重新安装一次 NPL。

八、浏览器插件（NPL Connector）

  1. 先启动 NPL。
  2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
  3. 打开「开发者模式」→「加载已解压的扩展程序」→ 选 browser-extension 文件夹。
  4. 打开论文页面，点工具栏 NPL 图标，确认论文名，选「直接归档」或「AI 精读后归档」，再选分类，保存。
  5. 有 PDF 直链会一起下载，并从页面 meta 抓卷 / 期 / 页码；抓不到就只存网页信息，后台继续尝试。
  6. 升级主程序后到扩展页点一次「重新加载」。
  7. 遇到出版社「安全验证 / Preparing your download」时，按提示先手动过验证，程序不会反复重试。

九、设置页要点

  • 模型与 API：地址、模型名、Key、测试连接。
  • 论文抓取：并发数、单篇重试、保存后监听手动下载（15 分钟内接管）。
  • 学术邮箱：用于 Unpaywall / OpenAlex / Crossref；未填 Unpaywall 时自动复用。
  • 数据与存储：补齐卷期页、备份、还原、回收站、存储目录。
  • 引文格式：列表 + 一句话生成自定义格式 + 导入 .csl + 预览 + 删除。
  • 剪贴板监听：可关闭（关掉后不读剪贴板）。
  • 端口：默认 8765；改了端口 Word 插件也用「端口」按钮跟着改。

十、数据与隐私

  • 程序数据：%APPDATA%\PaperWhale（数据库、设置、日志）。
  • PDF 文件：默认在「论文文件」目录（设置里可看实际路径）。
  • 便携版数据：exe 同目录 data\。
  • 只有调用大模型 / 联网补全时才发送必要文本或查询，不经过任何中转服务器。
  • 卸载不删除数据；彻底清空请手动删除上面的目录。卸载会移除 Word 模板与快捷方式。

十一、常见问题

双击没反应
看 %APPDATA%\PaperWhale\paperwhale.log。
端口被占用
程序会自动换端口；Word 里点「端口」按钮改成实际端口再「测试连接」。
Word 里没有 NPL 标签
确认 STARTUP 目录有 PaperWhaleMacros.dotm，重启 Word。
Word 提示「编译错误」
关掉报错窗口 → 那个文档不保存关闭 → 重启 Word；仍出现就重装一次 NPL。
点「插入引文」没弹窗口
确认默认浏览器可用、NPL 正在运行；Word 等待 240 秒，按 Esc 取消。
扫描版 PDF
没有文字层时选词、搜索和正文精读受限，可先用外部 OCR。
出版社下载失败
多半是限流 / 登录 / 人工验证，按提示手动过验证或稍后重试。
杀毒软件误报
PyInstaller 打包偶尔被误报，可加入信任。
