导入 PDF 文件夹

扫描一个文件夹里的 PDF：标题/DOI 能对上已有论文就补全文，对不上的自动新建条目。

EndNote 论文库迁移

在 EndNote 里 File → Export → 格式选 XML、勾选导出附件，导出到库旁边；这里选那个 .xml（或整个文件夹），元数据和 .Data/PDF 里的 PDF 会一起迁入。

Zotero 导出文件

迁移笔记推荐 Zotero RDF，导出时勾选「导出笔记」和「导出文件」。也支持 CSV / BibTeX / RIS 中的备注字段。

Zotero 导出文件夹

选择含 .rdf/.csv 和 files/ 的导出目录，PDF 与导出的笔记一起迁入。已有文献也能补入笔记。

Obsidian 文献库

扫描 vault 里的 Markdown 笔记（frontmatter 元数据）和随附 PDF。

DOI / arXiv / 网址

PDF 获取

托管下载消耗 OpenAlex 账户额度，超出免费额度时可能产生费用。默认关闭；公开出版社和仓储链接照常尝试。

选择登录学校或出版社的那个配置；再次获取时会刷新登录态。动态页面可在浏览器完成登录或验证后使用插件保存。

剪贴板监听

在本机盯着剪贴板：复制论文 DOI / arXiv 链接，或复制一段看起来像论文题目的文字，窗口左下角会问你要不要入库。

只在本机内存里比对最近几条，不写日志、不上传；不需要就关掉。

我的研究画像

写给 AI 的「我是谁」：方向、课题、在做的项目、关心的问题。新论文入库后，AI 会判断它和你的工作有什么关系。
