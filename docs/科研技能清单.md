# PaperWhale 相关科研技能清单（Agent Skills）

这些 Skill 已随程序打包到 `skills/` 目录，PaperWhale 会在论文精读、知识库问答和分类整理时自动启用对应规范；
上游客源与许可见 `skills/ATTRIBUTION.md`。

这些是安装在本机 `C:\Users\10498\.agents\skills\` 的 Agent Skill，供 Claude Code / Codex / 本机 Agent 在
**写论文、做综述、审稿、总结、文献管理**时调用。PaperWhale 程序本身走的是普通 OpenAI 兼容 API，
不会在运行时执行 SKILL.md；但这里的规范、提示词和流程可以直接用于配合 PaperWhale 做科研工作。

## 论文阅读与总结

| Skill | 用途 |
|---|---|
| `nature-reader` | 中英对照精读、全文翻译、图表公式对齐、基于原文提问 |
| `nature-paper-card` | 结构化精读卡：方法拆解、实验-结论证据链、局限、研究 idea |
| `deeppapernote` | 单篇论文 → Obsidian 风格高质量深读笔记（支持 DOI/arXiv/Zotero/PDF） |
| `doc-parser` / `pdf` / `table-extractor` / `smart-ocr` | PDF 解析、表格抽取、扫描件 OCR |

## 论文写作与润色

| Skill | 用途 |
|---|---|
| `nature-writing` | 起草/重构章节与论证，首次投稿材料 |
| `nature-polishing` | 润色、学术翻译、正文压缩、LaTeX 排版修复 |
| `academic-paper` / `academic-paper-writer` | 全流程论文写作流水线、分节写作 |
| `paper-writing-section` / `scientific-writing` | 单节写作、IMRAD 结构、报告规范 |

## 引用与文献规范

| Skill | 用途 |
|---|---|
| `nature-citation` | 为论点找/核 CNS 系列支撑文献，claim→source 映射 |
| `citation-management` | 检索、校验引用、生成 BibTeX |
| `bib-search-citation` | 从本地 BibTeX / Zotero 导出库里按主题/作者/年份找引用 |
| `pyzotero` | 用 Python 直接操作 Zotero 库（条目、分类、标签、附件） |

## 综述、审稿与返修

| Skill | 用途 |
|---|---|
| `literature-review` / `systematic-literature-review` | 系统综述、跨论文对比、APA/IEEE/BibTeX 输出 |
| `peer-review` / `academic-paper-reviewer` / `nature-reviewer` | 审稿意见、投稿前自审、多视角评审 |
| `scholar-evaluation` | 新颖性/严谨性/意义/清晰度评估 |
| `paper-revision` / `nature-response` / `rebuttal-writing` | 按审稿意见返修、逐点回复、rebuttal |
| `nature-statistics` / `stat-writing` | 统计报告审查、统计方法小节、图注统计 |

## 知识库与文献管理

| Skill | 用途 |
|---|---|
| `knowledge-ops` | 多存储层知识库的入库、去重、同步、检索 |
| `memory-management` | 长期记忆/术语表/内部简称管理 |
| `obsidian-vault` | Obsidian 笔记检索、创建、索引 |
| `file-organizer` | 按内容批量整理/重命名文件 |

## 常用触发方式

- 「用 nature-paper-card 精读这篇 PDF，给我方法拆解和证据链」
- 「用 systematic-literature-review 做这个主题的综述，输出 APA 引用」
- 「用 nature-reviewer 以审稿人视角挑这篇稿子的硬伤」
- 「用 nature-citation 给这段话补 CNS 支撑文献」
- 「用 pyzotero 把这批条目按分类整理进 Zotero」
- 「用 knowledge-ops 把这些笔记去重、建索引」
