# PDF 获取与诊断

本说明更新至 2026-10-28 的 2.5.2。需更新主程序与浏览器 Connector，才能同时使用后台和浏览器侧补强。

## 实际失败定位（2.5.2）

修复 DOI 跳到 Elsevier linkinghub 后，HTML Refresh 地址没有 PDF 后缀而被忽略的问题。声明的刷新跳转按 HTTP 导航处理，不占用文章展开的两层预算；仍受总请求数、循环检测与总时限限制。实际公开 DOI 试跑已能到达 ScienceDirect，但该环境随后仍返回403，不能据此声称目标全文已下载成功。

Connector 保存时会记录论文页面与插件环境各自的失败：HTTP状态、超时、网络请求失败、返回网页/不完整PDF、大小或跳转上限。浏览器未公开网络失败原因时，不直接断言是跨域或权限问题。弹窗同时显示文件校验或论文身份不匹配警告。

同一记录会显示在论文详情的“PDF 获取记录与来源”中，分为“浏览器插件下载记录”和“后台补抓记录”。当前PDF是否已归档按实际文件判断，与旧后台任务的失败历史分开显示；后续后台任务不会覆盖插件证据。URL查询参数、片段和用户信息会去掉，不记录Cookie或原始错误消息。旧版插件产生的历史失败不能凭空补回，更新并重载Connector后再次保存才会生成新记录。

## ScienceDirect 与机构代理（2.5.1）

- 识别 PDF 按钮、页面下载 JSON 和 pdfft 正常下载入口，跟进中转页的刷新地址或正文链接。保留来源提供的签名参数，不编造下载凭据。
- 点击 Connector 保存时，才尝试展开安全的 PDF 菜单，最多等待 1.5 秒读取新链接；已展开的菜单保持原状，只关闭本次打开的菜单。不会为了提取链接自动点击会导航到其他页面的普通下载链接。
- 机构代理页须提供可信 ScienceDirect canonical / citation_public_url 且与当前文章 PII 一致，才应用专用解析。相对下载地址保留实际代理来源；不会把代理域名猜写成公共站点。
- 保留实际原文页面 URL，优先由当前标签页携带浏览器会话下载。回退本机请求时可带浏览器 User-Agent；请求来源同站保留路径和查询参数，跨站只发送来源域名，HTTPS 降级不发送来源。诊断仍去掉所有查询参数。
- 多个候选优先正文，补充材料排后；插件最多尝试 4 个候选，共享 90 秒浏览器阶段预算，中转页继续受请求数、深度、80MB PDF 和 2MB HTML 限制。用户手动填写的 PDF 地址优先；保存前后检查标签页归属，防止切篇后错存。
- 后台共享下载器对同一主机请求启动至少间隔 1 秒；429 和带 Retry-After 的 503 按服务器时间冷却，较长等待直接提示稍后重试。连续 3 次 403 暂停同一凭据上下文约 60 秒，换用有效登录态仍可尝试；其他站点继续运行。此状态仅保存在进程内，不保存原始凭据。

更新插件后，在浏览器扩展管理页重载 Connector。若仍需登录或人工验证，请在原浏览器页面完成后再保存；上述适配不保证所有出版社或机构环境都能自动下载。

## 使用入口

论文详情中的“自动找 PDF”会尝试已有 arXiv ID、原文链接、OpenAlex、Crossref、Unpaywall、Europe PMC、DOI 落地页、Semantic Scholar、标题匹配和所选浏览器登录态。

详情里的“PDF 获取记录与来源”可查看本次或最近一次尝试：来源、去除查询参数的 URL、HTTP 状态、失败类型和成功来源。记录保存在本地数据库；展开时读取最新状态，运行中可收起再展开刷新。

超时、限流、服务异常、登录/人工验证页、链接失效、文件无效、文件过大、论文不匹配分别记录。403 不再直接解释成“需要付费订阅”。旧记录没有逐路线证据，只有再次尝试后才能产生新的诊断。

## 设置 → PDF 获取

- **OpenAlex API Key**：填写自己的 Key，留空保留已保存值；设置查询不会返回该 Key 的明文。也支持 `OPENALEX_API_KEY` 环境变量。
- **使用 OpenAlex 托管 PDF**：默认关闭。启用后，命中 `has_content.pdf` 的论文可以使用 OpenAlex 自己保存的副本，减少对原出版社地址的依赖。下载消耗账户额度，超出免费额度时可能产生费用；未启用不使用该托管路线。
- **Unpaywall 联系邮箱**：可选，但使用该查询源需要真实联系邮箱；也支持 `PAPERWHALE_UNPAYWALL_EMAIL`。不再自动使用虚构邮箱。
- **浏览器和用户配置**：选择登录了学校或出版社的 Edge/Chrome 配置，例如 `Default` 或 `Profile 2`。候选列表只枚举配置目录，不读取 Cookie。
- **自动使用所选浏览器的登录态**：可关闭。开启时，每次手动获取会刷新所选配置；批量任务共用缓存。Cookie 按目标主机、路径和 HTTPS 匹配，不混合其他浏览器或用户配置，也不把一个网站的手写 Cookie 转发给其他网站。

浏览器 App-Bound Cookie 仍依赖本机浏览器和 rookie-cookies，可能启动临时浏览器，是否成功取决于环境。程序不再根据“刚出现的窗口/进程”猜测并关闭浏览器。动态生成的下载链接、人工验证或复杂机构登录仍可能需要在浏览器完成后用插件保存。

## 下载与版本

后台、DOI 导入和插件后端使用共享下载器：解析网页元标签、PDF 链接、下载按钮、相对链接和部分内嵌查看器，最多跟进两层网页，限制请求数与总耗时。没有 `.pdf` 后缀的地址也会按实际返回内容判断。

文件流式写入临时目录，上限 80MB，并验证 PDF 可打开且有页面。标题明显不匹配或明确为错误补充材料时不自动归档；没有可用文本、标题不确定等情况标记为未验证，不承诺已确认版本身份。下载期间用户已经手动补上的 PDF 不会被后台结果覆盖。

成功时保存来源、最终地址、SHA256、获取时间、匹配结果和来源提供的版本/许可。来源未给版本时显示未确定，不凭空认定是正式出版版。论文 AI 上下文会读取这些版本信息。

网络超时、部分 5xx 和短暂限流最多重试一次。`Retry-After` 较长时保留等待提示，留待稍后重试，不提前密集请求。每篇后台任务总预算约 150 秒；单个仍在进行的网络操作可能在其自身超时后才结束。

任务状态与诊断保存在 `pdf_fetch_jobs`，重启恢复 queued/running 的未完成任务；failed 不自动重复执行。手动点击或批量获取可重新尝试。

## API 与代码

- `/api/pdf-fetch/start`、`/one/{paper_id}`、`/status` 保留原路径。
- 新增 `GET /api/pdf-fetch/report/{paper_id}`，返回持久化诊断。
- `pdf_download.py`：共享下载、落地页解析、流式大小限制、校验与有限重试。
- `pdf_trace.py`：结构化诊断与 URL 脱敏。
- `pdf_domains.py`：线程安全的主机间隔、服务器冷却与凭据隔离的连续拒绝暂停。
- `pdf_fetch.py`：来源调度、任务恢复、归档和来源记录。
- `metadata.py`：OpenAlex 结构化候选和托管地址识别。

## 验证与限制

新增回归：`.venv/Scripts/python.exe -m unittest discover -s tests -p test_pdf_acquisition.py -v`。测试使用临时目录、真实 PDF 样本和模拟 HTTP，不读取真实登录态。

插件下载测试：`node --test tests/pdf_extension.test.mjs`。真实界面回归：`node tests/ai_conversations_ui.mjs`，新增设置保存、Key 脱敏和诊断入口验证。

可选公开网络对照：`.venv/Scripts/python.exe tests/pdf_public_probe.py`。本次已在临时目录实测 arXiv `1706.03762`，取得约 2.2MB PDF，标题匹配通过。OpenAlex 托管下载及浏览器登录态使用模拟链路验证，未使用用户 Key 或真实 Cookie 做付费/登录下载实测。

2026-10-27 的历史只读汇总为 11 篇缺 PDF，旧报错不足以区分真实根因；本批未读取或批量重试真实库，不能据此声称成功率提升了某个百分比。
