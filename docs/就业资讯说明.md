# 就业资讯

左侧“就业资讯”收集科研和企业招聘线索，重点支持高校、研究所、博士后，以及企业研发、校招、社招和实习。

1. 在需求框填写想找的岗位、领域或地区，选择“普通搜索”或“AI 帮我找”。普通搜索不需要配置大模型；AI 会理解需求、扩展查询，再依据实际检索结果分析匹配。
2. 每条线索可以查看原公告，并标记“待处理、已收藏、已投递、已忽略”。支持备注、分类和本地文字筛选。相同链接再次检索到时会合并，保留之前的处理状态和备注。
3. 在“就业偏好”填写常用关键词、地区和愿意提供给 AI 的学历/技能背景。研究画像只有勾选后才会参与匹配；不会读取论文全文或其他入口的聊天。就业检索历史单独保存，可以清空、撤销清空或停止当前生成。
4. “保存招聘链接”可以收录自己在招聘网站、单位官网找到的公告。程序不会代替你登录、提交简历或投递申请。

搜索摘要可能不完整或过期，招聘单位、学历、薪酬、岗位要求与截止日期请以原始公告为准。未核实的字段不会由 AI 补成事实；结果可能来自转载站，来源域名会显示在条目中。网页搜索无结果时可换具体岗位词、手动保存链接，或稍后再试。

就业线索、备注、状态、偏好和独立对话保存在本机，并包含在元数据备份中。清空就业对话不会删除已收录的招聘线索。首版手动发起检索，不自动定时采集。


2.7.62 起，普通搜索也会把自然语言拆成方向、岗位类别和地区；长三角会分散检索上海、苏州、杭州等地，并同时核查沪苏浙皖范围。搜索不会仅因单位名称含有某地区就认定工作地点符合。

主列表展示有来源正文依据的岗位/公告和用户主动保存的链接；招聘目录、方向相近、来源要求登录、正文或工作地点未核实以及原有旧线索，会放入折叠区。已读取正文不等于证明当前仍在招聘，没有明确有效期时仍标为未核实。可以展开条目的核查依据和本轮实际查询语句了解筛选原因。无合格结果时不会自动降低要求凑数。
