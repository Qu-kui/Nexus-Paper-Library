# 阅读窗口第一批增强

2026-10-27 发布的 2.3.0 已包含引用跳转与返回、批注整理导出、章节导航、AI 材料范围提示。原有阅读进度、搜索、批注和独立论文对话继续保留；旧版用户需升级后使用。

## 引用跳转与返回

PDF 自带的内部链接可以跳转到目标页及页内位置，外部 HTTP/HTTPS、邮箱链接可以打开；脚本、本地文件等链接不执行。工具栏增加“返回 / 前进”，恢复跳转前的页码和页内位置。目录、批注、搜索和手动页码跳转也记录来源位置。当前论文的跳转历史最多保留 60 个位置，切换或关闭论文后重置。

这一步使用 PDF 原有链接；没有链接的正文图号、公式号或参考文献编号不会自动推断成可点击链接。

## 批注筛选与导出

批注标签页可以组合筛选颜色、是否有备注、引文/备注关键词和章节。上方显示“显示 X / Y 条批注”。筛选仅影响侧栏列表，PDF 上的高亮仍保留。没有结果时可重置筛选。

“导出筛选批注”下载当前筛选结果的 Markdown 文件，包括论文名称、作者、年份、DOI，以及每条批注的页码、章节、原文和备注。重置筛选后导出全部批注。修改章节会同步更新批注所属范围；不改写已有批注。

## 缺少目录时的章节导航

优先读取 PDF 内置目录；没有可用目录时，根据本地文字及版式识别章节。显示识别进度，可停止或重新识别，不调用 LLM，也不联网。

自动识别最多处理前 120 页、每页 20,000 个文字片段和 400 个章节。扫描页没有文字时不会生成虚构目录。识别结果可能不准确，支持添加、调整或删除章节，包括名称和起始页。手动调整保存在本机，绑定论文和 PDF 指纹；重新识别会替换这些调整。点击目录后继续留在目录标签页。

按页定位的章节范围存在边界限制：同页开始的多个子节无法可靠分割正文；图表或双栏排版也可能影响标题识别。

## AI 本轮材料

论文对话上方显示当前论文、阅读页、附选文和已保存附件。正文选文在点击聊天输入框后仍保留，并可手动移除。

- **解释本页**：准备本页文字。
- **梳理本节**：根据章节导航准备当前节，最多 12 页；没有可靠章节时按钮不可用。
- **结合批注回答**：准备本篇全部批注的引文、备注和页码，并显示数量。它不受批注标签页的列表筛选影响。

这三个按钮先准备材料和问题，用户可以修改问题后点击“问”。已有输入和材料提取期间的新编辑不会被自动问题覆盖。材料预览可以移除，提取期间发送按钮暂不可用。

选文最多 4,000 字，附加材料与选文合计预算约 10,000 字；会标明截断，最终请求不超过问题接口的 16,000 字符上限。页码绑定所准备的材料：准备第 3 页后翻到第 4 页，发送时仍以第 3 页作为材料定位。切篇后旧提取结果不会混入新论文。

默认联网和深度思考保持。准备材料只用于聚焦本轮问题，模型仍可结合本篇既有上下文和附件，不能据此认定已逐字读取完整论文。对话显示材料摘要和问题，实际引用文本单独保留给模型历史，不把内部传输格式铺在聊天区。清空会话同时移除当前尚未发送的选文和准备材料。

联网检索和本地检索使用单独保存的原始问题，不把引用材料或内部说明当作搜索关键词。链接区域同时绑定文档、缩放和原始画布，避免缩放后出现错位的旧链接。

## 验证

使用新建临时数据目录、三页合成 PDF、mock LLM 与 headless Edge；未访问真实文献库或已安装程序。

新增 Node 测试覆盖导航、链接协议、英文/中文标题、批注过滤/真实下载、材料归属、截断、输入保留及页码冻结。`tests/reader_first_batch_ui.mjs` 使用真实原生 PDF 链接测试页内偏移、前进返回、自动及手动章节、筛选导出、当前页/章节/批注请求、选文保留和移除，以及切篇后迟到的链接/目录/材料结果失效。

实际界面截图位于 `docs/ui-review-2026-10-27/reader-first-batch/`。图表/公式框选、多段双语对照、OCR、书签与阅读待办属于后续批次，本次没有实现。

最终验证结果：Python 73 项通过，Node 36 项通过（含本轮新增 28 项）；新增阅读窗口 Edge 8 组、原阅读器 11 组、原会话 8 组及 AI 反馈流程均通过。独立规格复核与代码质量复核完成；曾发现的页内目录偏移、章节筛选刷新、检索问题被材料挤占和缩放后旧链接覆盖均已修复并有针对验证。
