# 发现论文：推送与 AI 研究检索

2.5.0，2026-10-28。

## 谷歌学术推送

上方模块显示通过邮箱同步的 Google Scholar 快讯，保留“同步邮件”和“账号设置”。可以查看论文、加入文献库或忽略；同步邮件不改变下方 AI 研究话题。邮件多时在推送模块内部滚动。

## AI 研究检索

下方模块可以直接输入中文请求，例如：

- “我想了解单像素成像最近一年的新进展。”
- “帮我找找关于偏振成像的论文，重点关注弱光条件。”
- “帮我梳理单像素成像的发展脉络，按阶段整理论文。”

点击“开始研究”，或按 Ctrl / ⌘ + Enter。AI 会理解问题、规划最多 3 个互补的中英文检索词，再查询 Crossref、OpenAlex、arXiv 和 Europe PMC 的公开学术元数据，并按真实返回记录筛选候选。Europe PMC 补充生物医学与相关交叉领域。默认深入分析，支持显示实际模型分析内容、停止及重试；检索计划使用的内部格式不显示为聊天正文。

模型分析和回答增量共用一个最高 240 像素的滚动区，默认跟随新内容；向上翻看时保留阅读位置，回到底部后继续跟随。折叠分析内容的选择会在实时刷新时保留。这项规则同样用于单篇问答、知识库问答、画像和分类助手。

“最新进展”未指定时间时默认近一年，界面显示实际检索日期范围；也可明确写“近三个月”“2024 年以后”。“发展脉络”围绕检索到的论文分阶段整理，并对真实返回的 OpenAlex 种子尝试一次后向参考文献和一次前向引用查询。引用关系只说明文献联系，不能据此认定研究结论或方法优劣。旧候选显示“此前”，不会占用新一轮编号。

页面直接显示候选处理列表，不再重复展示一整份 AI 文献清单。折叠的研究请求记录只显示用户问题，历史仍保存在本话题上下文中。

## 追踪某篇论文的后续研究

可以直接输入「Brownian spin-locking effect 这篇论文之后的相关研究」，也可以用 DOI 指定原文。系统先查询原文元数据，题名有歧义时会提供可选论文。确认后显示原文、DOI 和实际起始日期。期刊论文默认采用在线发表日期，已核实到预印本时可用「从预印本起查」，也可以手动改日期。

直接引用原文和同方向候选分别显示。「仅看直接引用」依据引用索引的证据筛选。空结果可重试本轮或扩大同方向检索。直接引用来源失败时可单独重试，保留的旧候选仍可在此前的候选里查看。检索详情可展开查看检索式、日期和来源提示。

## 阅读研究文件

「添加研究文件」支持 PDF、DOCX、TXT 和 Markdown，每个话题最多 8 个文件，每个文件最多 25 MB。上传后在本机提取文字并保存到当前话题。可以点击「阅读附件」概括内容或回答输入框里的问题，也可以点击「开始研究」用附件线索找论文。

模型接收的是文字节选。单个文件提取保留至多 30,000 字符，每轮选用至多 4,500 字符，所有附件合计至多 12,000 字符。扫描版 PDF 需先提供可选中文字的版本。可以从话题移除附件，之前的阅读回答仍可在该话题里展开查看。

## 用户处理候选

论文以行列表显示，包括原文题名、中文译名、作者、年份、来源、处理状态。新研究在筛选时同时翻译题名；旧候选或翻译失败的候选可点击“补齐中文题名”，每次最多处理 50 篇、每批 10 篇。译名只用于显示，不替换原题名，也不参与身份去重。未完成的译名会明确提示，可重试；原本为中文的题名不重复显示。展开“推荐理由与详情”可查看摘要、推荐理由、阶段和标识符。

- **查看论文**：打开真实的 DOI、arXiv 或来源页面；不表示一定有免费全文。
- **加入文献库**：明确点击后才导入元数据，并交给现有 PDF 获取队列继续尝试补齐全文。
- **忽略**：隐藏待处理候选，可切换“已忽略”查看并恢复。
- **待处理／已入库／已忽略／全部**：按状态查看本话题候选。

搜索不会自动入库。已在文献库的论文有标识；重复加入不会重复建库或反复启动获取。去重优先使用 DOI/arXiv 等标识，同名但标识冲突的论文不会仅凭题名合并。忽略和入库选择会跨刷新、后续搜索保留。

## 独立研究话题

每个研究话题分别保存问题、回答、候选和处理状态，可以继续追问，也可以新建话题。切换话题不会把旧话题的晚到结果显示到新话题中；原话题完成的结果仍保存在原处。

话题旁的“删除话题”会把话题、候选和对话一起移入回收站，可立即撤销，也可在设置的回收站恢复。已经加入文献库的论文保留。删除会使正在执行的旧检索和补译失效；即使立即恢复，旧结果也不能写回恢复后的话题。

已保存研究画像仅用于理解用户目标，不作为论文证据。研究检索与单篇阅读、知识库问答、画像访谈、分类助手以及谷歌学术推送分别保存上下文。新话题没有其他话题的未确认讨论。

候选、研究轮次及话题对话包含在现有元数据备份中。2.3.x 旧备份没有发现论文表时仍可恢复；不完整的新表结构会被拒绝，避免替换当前数据。

## 检索范围

候选筛选依据真实来源元数据和可用摘要。每轮最多 8 次主题来源请求，发展脉络最多追加 2 次引用查询。原文追踪另有原文核对及前向引用查询。主题和引用查询共享 38 秒预算，最终最多 30 篇候选。原文核对和模型耗时另计。来源超时或失败时保留其他来源的可用结果，并显示提示。日期不完整会提示，完全没有日期的记录不会被当作明确时间范围内的结果。

安装包和便携版都内置 `academic-discovery` 检索技能，规划和筛选会实际加载其规范：中英文专业术语与同义词扩展、互补检索式、相关性筛选、真实来源核验及忠实题名翻译。四个检索接口和引用追溯代码也一并打包，无需安装 Codex 或其他 Agent 插件；大模型继续使用设置中配置的兼容接口。

历史对话按节选预算保留，过长摘要也会节选。模型只能选择已提供的记录编号并给出相关性／阶段说明和中文译名，原文题名、标识符和链接来自数据源，不接受模型补写的文献清单。即使模型整理失败，可用来源记录也会保留并注明尚未确认相关性。

所用数据源接口说明：[Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、[OpenAlex](https://help.openalex.org/api/)、[引用追溯](https://help.openalex.org/how-to/api-recipes/)、[arXiv](https://info.arxiv.org/help/api/user-manual.html)、[Europe PMC](https://dev.europepmc.org/RestfulWebService)。本功能不自动注册数据源账户，也不自动购买 API 额度。

## 验证记录

新后端测试使用临时库、模拟 HTTP 与模型结果；浏览器测试模拟邮件快讯和研究结果。覆盖自然语言三种意图、来源解析／部分失败、日期预算、编号真实性、去重、明确入库、备份兼容、话题隔离、停止重试以及候选处理与晚到搜索结果的竞态。

另用公开关键词测试了实际来源接口，未使用用户 LLM 密钥或真实邮箱。实际接口可用性仍受本机网络和来源限流影响。没有对真实文献库或当前已安装程序执行升级。
