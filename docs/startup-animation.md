# NPL 启动开屏

采用用户最终确认的留白 N 书页标志与酒红紫色 `#6e0342`。三条细光线在画面中央交错环绕，分别收向书页的真实转角，带出书页轮廓与实体填色；图标轻滑向左，与依次落定的 NPL 字标、全名组成完整标识。短暂停留后，左右页连同白色背景沿书脊向两侧打开，直接露出真实主界面。

| 时间 | 动作 | 连续性 |
| --- | --- | --- |
| 0–1.19 秒 | 酒红、玫紫、冷蓝三条光线错峰环绕 | 每条弧线终点接到书页的真实转角 |
| 0.43–1.72 秒 | 光线勾勒书页边缘，再收成酒红色实体 | 轮廓与填色共用生产 SVG 的五条路径 |
| 0.58–1.88 秒 | 图标由画面中央轻滑到左侧，字标、全名与口号跟随落定 | 同一个图标持续运动，文字轻微弹性错峰 |
| 1.88–2.20 秒 | 完整标识静止，所有光线均已收束 | 给用户辨认时间 |
| 2.20–3.00 秒 | 左页向左，右页与字样向右，露出文献库 | 同一组书页持续移动，无换帧转场 |

主程序同时初始化，不等待动画。初始化较慢时在完整标识处稍停，最迟约 5.3 秒进入主界面。独立于动画模块的 6 秒保护会解除遮罩；动画脚本或样式缺失也不会阻止主程序初始化。

每次桌面进程生成新的启动标记。页面在首次绘制前消费标记并移除 URL 参数；同一窗口刷新、页面切换、打开阅读器、隐藏到托盘后恢复都不会重播。浏览器直接访问和 Word 引注选择页不播放。支持 Esc、跳过按钮、运行中切换系统减少动画设置；减少动画模式直接进入应用。标题栏控制按钮保持可用。无启动音效。

使用 [onetake](https://github.com/feitangyuan/onetake) 技能进行分镜与运动编排，以其纯时间函数采样生成原生 Web Animations 关键帧。该项目作者为 Patrick，技能库许可为 PolyForm Noncommercial 1.0.0；此处用于课题组非商业研究应用的设计制作。应用运行不依赖 Codex、联网、视频播放或 onetake 库；未复制分发该技能的运行库、字体或音效。短开屏沿用用户指定的光线环绕生成 → 展开概念，采用 3 秒交互时长，无宣传片镜头或音轨。光线头部的位置在初始化时按 SVG 几何一次性采样，播放阶段使用原生关键帧，无 JavaScript 逐帧循环。

修改流程：

1. 修改 `web/brand/npl-mark.svg`，保持五个 `data-part` 路径名。
2. 修改 `tools/compose_startup.mjs` 的时间轴，在安装 onetake 技能的开发机运行 `node tools/compose_startup.mjs`；可用环境变量 `ONETAKE_SKILL_DIR` 指定位置。
3. 生成的 `web/js/startup-motion.js` 与 `startup.js`、`startup.css` 随应用打包，无新增运行依赖。
4. 运行 `node tests/startup_ui.mjs` 验证实际应用播放、光线收束、只播一次、跳过、减少动画、异常降级与多尺寸构图；设置 `NPL_RECORD_STARTUP=1` 可录制预览。`pw-debug/npl-startup-orbit` 保存关键帧和测试记录。
