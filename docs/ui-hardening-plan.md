# 界面与功能补强实现计划

2026-10-27。用户已批准审查报告中除 AI 模式开关之外的全部改动；AI 保持默认联网、深度思考，改为展示模型实际输出的思考摘要和进展。无需重复确认方案。

## 实施分工与接口

- [x] 后端数据：全库排序分页、文件存在性与独立错误状态、批次任务统计/失败重试、聊天撤销和论文回收站、元数据备份恢复。新增字段增量迁移，测试隔离。
- [x] 阅读器：按论文恢复阅读状态、侧栏拖动/折叠与适配、逐命中搜索高亮/取消、内联批注编辑、异步归属保护、来源与笔记操作。独立模块和样式，避免与全局布局同时修改。
- [x] 列表/设置：后端 sort/limit/offset 分页，自适应列宽/密度/列配置，任务中心，状态徽标，详情异步隔离，清筛选，分组保存和未保存提示，键盘/弹窗焦点/aria。
- [x] AI：保留原默认值，模型真实 reasoning_content 或简短分析摘要持续显示；支持停止/重试；区分引用与检索候选、摘要与全文；多论文明确比较和回答存笔记。

后端兼容原路径。列表 GET /api/papers 增加 sort，返回 total/limit/offset；状态包含 pdf_state、index_state、analysis_state、category_error、index_error、analysis_error。PDF/精读状态接口增加 batch_id，并支持失败重试。会话 clear 返回可撤销记录，POST /api/ai/conversations/{scope}/undo 恢复。维护接口统一放 /api/maintenance 下。

AI 进展模块提供当前请求的 ContextVar 和 begin/finish/emit 接口，conversations.turn 在确认作用域与版本后开始、结束；客户端只显示自己会话、自己轮次的进展。没有模型思考内容时只显示真实处理阶段，不生成假进度。
