# 新手指引

首次使用时，开屏结束后会出现覆盖在真实界面上的导览。高亮框标出当前功能，介绍卡片提供「上一步」「下一步」「跳过」；步骤会自动切换到对应页面并滚动到目标位置。按 Esc 可退出。

主指引共 13 步，依次介绍导航、模型连接、研究画像、PDF 导入、链接添加、文献筛选、进入阅读器、发现论文、多篇问答、方法参数、复习卡片、插件与开始使用。导览不提交表单、不导入文件、不启动模型任务；打开页面时原有的数据加载照常进行。需要填写或操作时，可以先退出导览。

完成主指引后，第一次打开论文会出现 4 步阅读指引，介绍顶部工具、正文批注、精读与独立问答、重看指引入口。主指引不自动打开用户论文，空文献库也能完整走完。

重看入口：

- 桌面标题栏「帮助 → 新手指引」。在阅读器中使用此入口会打开阅读指引。
- 「设置 → 关于 → 重新开始新手指引」。
- 阅读器顶部「阅读指引」。

跳过、完成或中断后不会每次启动重复弹出。此前已选择「稍后再说」的老用户不会因升级而自动弹出；仍可从上述入口手动打开。状态记录在本机当前浏览器来源的 localStorage：`npl.onboarding.v1` 与 `npl.onboarding.reader.v1`。清除网页存储或更换服务地址可能再次出现。

适配窗口缩放、页面滚动和系统减少动态效果设置。原生窗口标题栏、最小化、最大化和关闭保持可用；通过标题栏导航到其他页面会结束当前导览。阅读指引中的 Esc 只退出导览，保留论文阅读器。
