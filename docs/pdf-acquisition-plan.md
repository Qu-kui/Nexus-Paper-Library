日期：2026-10-27。依据用户确认的六项改进，直接在当前会话实施，不重复确认。

## 目标与边界

优先补齐开放获取路线、最终出版社登录态和真实失败诊断；统一下载校验，补充有限重试、任务恢复与版本来源。测试使用隔离目录与模拟 HTTP。真实失败条目只读取元数据，不调用浏览器解密、不批量下载、不修改已有用户文件。OpenAlex 内容下载由用户启用并提供自己的 Key，默认关闭，额度和可能产生的费用在设置中说明。

## 核心验收

带 Key 的 OpenAlex 托管候选可下载且不泄露 Key；不含 `.pdf` 的直链不会被丢弃；OA 落地页能提取相对 PDF 链接；DOI 跳转后只发送目标站匹配的 Cookie，多个用户配置不混合；限流与超时不被说成付费墙；假 PDF、错误论文及超限文件不覆盖原论文；任务重启可恢复，状态与诊断可查询。
