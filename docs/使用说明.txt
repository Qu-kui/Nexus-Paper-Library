Nexus Paper Library (NPL)  使用说明

  兼容说明：程序仍使用 PaperWhale.exe，原数据目录、数据库文件和 Word 模板文件名不变；桌面快捷方式和应用界面显示 Nexus Paper Library（NPL）。
========================================

当前发布版本：2.7.54

一、这是什么
  本地优先的 AI 文献管理桌面程序：导入 / 下载论文、AI 精读、全库问答、
  方法与参数库、复习卡片、Word 引文插件。所有文献、笔记、PDF 都保存在你自己的电脑上。

二、安装
  1. 双击 NPL-2.7.56-Setup.exe
  2. 点「确定」自己选择安装文件夹（对话框里可以「新建文件夹」），
     或点「取消」使用默认位置
  3. 确认安装路径后点「是」，安装完成会自动启动
  4. 桌面 / 开始菜单会创建快捷方式，可在 Windows「应用和功能」里卸载
  5. 如遇 Windows SmartScreen 提示：点「更多信息」→「仍要运行」
     （安装包没有购买代码签名证书，属正常现象；可用 SHA256SUMS.txt 校验文件）

  静默安装（批量部署）：
    NPL-2.7.56-Setup.exe --silent --dir "D:\Apps\PaperWhale"
    可加 --no-launch 表示装完不自动启动。

  便携版：解压 NPL-*-portable.zip 到任意目录，双击 PaperWhale.exe，
  数据保存在 exe 同目录的 data\ 里，整个文件夹可拷走。

  升级安装：安装器会自动识别正在运行的 NPL，先正常关、关不掉再强制结束；
  仍失败会提示你手动从托盘退出（或右键以管理员身份运行安装包）。
  已打开的 Word 不会自动关，升级完请重启一次 Word（见「八、Word 插件」）。

三、系统要求
  - Windows 10 / 11（64 位）
  - Microsoft Edge WebView2 Runtime（Win10/11 一般自带；缺失时会退回浏览器打开）
  - 使用 Word 插件需要 Microsoft Word 2016 及以上（本机 Word 2021 已验证）

四、第一次使用
  1. 打开「设置」，填任意 OpenAI 兼容 API：
       DeepSeek : https://api.deepseek.com/v1       模型 deepseek-chat
       OpenAI   : https://api.openai.com/v1         模型 gpt-4o-mini
       通义千问 : https://dashscope.aliyuncs.com/compatible-mode/v1  模型 qwen-plus
       本地Ollama: http://127.0.0.1:11434/v1         模型 qwen2.5:14b
  2. 填 API Key，点「保存设置」，再点「测试连接」
  3. 到「我的研究画像」写清你的方向和在做的项目，新论文会分析与你的关联
  4. 往「导入 / 添加」里拖 PDF，或粘贴 DOI / arXiv / 网址，或去「发现论文」检索
  5. 从 Zotero / Obsidian 导入的条目如果没有 PDF，程序会在后台自动尝试补齐；
     也可以点文献库右上角「补齐 PDF」手动触发

五、导入文献
  支持的入口：
  - 拖入 PDF 文件（自动读标题、作者、DOI，再按 DOI 补卷期页等信息）
  - 粘贴 DOI / arXiv ID / 网页链接导入
  - EndNote XML、RIS、BibTeX、Zotero RDF、Zotero CSV 批量导入
    （按 DOI、arXiv ID、归一化标题判重；命中则补全空字段和缺失 PDF，不重复入库）
  - 浏览器插件一键保存（见「九、浏览器插件」）
  - 「发现论文」：中文描述研究主题，AI 返回候选论文，可入库或忽略
  - 剪贴板监听：复制 DOI / arXiv 链接 / 像论文题目的文字，程序会自动提示
  - 参考文献外扩：对一篇论文列出它的参考文献 / 引用它的文献，可批量入库并补 PDF

六、文献库
  - 左侧分类支持三级：先列第一级，点进某级才展开下一级；选中父级会筛出整棵子树
  - 列表所有列可拖动调宽；缺 PDF 的条目可在列表里直接筛出
  - 右键「编辑信息」可改标题、作者、年份、期刊，以及卷 / 期 / 页码
  - 老条目缺卷期页：设置 → 数据与存储 →「补齐卷期页」，按 DOI 批量补（只补空值）
  - 回收站可恢复误删条目；备份 / 还原入口也在设置页
  - 「分类助手」可只整理未分类，或对所有论文重新分类（执行前会确认，
    可选择是否把 PDF 一起移到新分类目录），进度在任务中心查看

七、AI 功能
  - 单篇 AI 精读：生成摘要、关键点、方法、结论，并可追问
  - 全库问答 / 知识库：基于你的库回答问题，会给出引用来源
  - 阅读器：划词翻译 / 解释、批注、章节识别、本页 / 本节 / 批注 AI 材料
  - 方法与参数库（左侧「方法 / 参数」）：从论文里抽方法、实验参数、材料、设备，
    支持搜索、按状态筛选、单篇或全部提取；结果可当方法参考库用
  - 复习卡片（左侧「复习卡片」）：把论文里的知识变成「可迁移知识卡」——
    问题是通用原理 / 取舍 / 适用边界，离开这篇论文也成立；支持生成、今日待复习、
    评分（1 放弃 / 2 困难 / 3 一般 / 4 简单，按 SM-2 排下次复习时间）
  - 任务中心：精读、PDF 抓取、方法提取、卡片生成、分类整理都是批次任务，
    显示进度、成功 / 失败数、失败原因，可「仅重试本批失败项」，关掉窗口再打开也能看到
  - AI 每一步都只用你配置的 API Key，不经过任何中转服务器

八、Word 插件（插入引文 / 参考文献）
  安装器会把模板装到 Word 的 STARTUP 目录，Word 里会出现「NPL」功能区标签。
  注意：装完 / 升级后请**重启一次 Word**，否则还是旧模板。

  功能区按钮：
  - 插入引文：打开独立的「添加引注」网页窗口（NPL 风格，不再是灰色对话框）
      · 左侧分类树（可展开 / 收起，括号里是含子类的篇数）、顶部搜索、
        右侧条目表（标题 / 作者 / 年份 / 期刊，白 / 浅绿交替）
      · 鼠标滚轮正常滚动；Ctrl / Shift 多选；双击某行直接插入；Enter 插入；Esc 取消
      · 也可以先按分类挑（把某篇文章的参考文献单独存一个分类，插入时直接选）
      · 选完点「插入引文」，窗口关闭，Word 里立刻插入并自动重排编号；
        点「取消」或直接关窗口，Word 会立刻停止等待（不会卡住）
  - 插入 / 更新参考文献：第一次放到文末；之后点它或「刷新」都原地更新，不会重复追加
  - 刷新：库里改了标题 / 年份 / 卷期，或手动移动了引文位置，点一下按文档顺序重排编号
  - 引文格式：打开可搜索的格式列表，内置 APA / MLA / Chicago / IEEE / Nature / GB-T 7714，
    以及你自己生成或导入的格式；当前格式标「← 当前」，数字型标「（数字型）」
  - 端口：Word 插件连本机 NPL 的端口（默认 8765）
  - 测试连接 / 使用说明

  编号规则（数字型格式，如 IEEE / Nature / GB-T 7714）：
  - 单篇 [1]，两篇 [1,2]，连续三篇及以上折叠成 [1-3]；不连续如 [1,2,5]
  - 编号永远按引文在文档里的先后顺序；在你已有的引文**前面**再插入，
    后面的会自动顺延（例如原来 [1-6]，前面插两篇后变成 [1,2] [3-8]），
    插入后自动刷新，不需要手动点「刷新」
  - 引文以书签保存：不要手动删引文文字；删了重新插一次即可

  模板位置：%APPDATA%\Microsoft\Word\STARTUP\PaperWhaleMacros.dotm
  Word 里如果提示「编译错误」，通常是旧的临时文档或旧模板：关掉报错窗口、
  那个文档不保存关闭，重启 Word 即可；仍不行就重新安装一次 NPL。

九、浏览器插件（NPL Connector）
  安装包目录里 browser-extension\（或 release 里的 NPL-*-Connector.zip）
  1. 先启动 NPL
  2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions
  3. 打开「开发者模式」→「加载已解压的扩展程序」→ 选择 browser-extension 文件夹
  4. 打开论文页面，点工具栏 NPL 图标，确认论文名，选「直接归档」或「AI 精读后归档」，
     再选归档分类，点保存
  5. 有 PDF 直链会一起下载，并会从页面 meta 抓卷 / 期 / 页码；
     抓不到 PDF 就只存网页信息，后台继续尝试
  6. 升级主程序后，如果插件行为没变，到扩展页点一次「重新加载」即可
  7. 遇到出版社「安全验证 / Preparing your download」页面时，程序会提示先手动过验证，
     不会反复重试刷失败次数

十、设置页要点
  - 模型与 API：地址、模型名、Key、测试连接
  - 论文抓取：并发数、单篇重试、是否在保存后监听手动下载（15 分钟内接管）
  - 学术邮箱：用于 Unpaywall / OpenAlex / Crossref 的联系邮箱；没填 Unpaywall 时自动复用
  - 数据与存储：补齐卷期页、备份、还原、回收站、存储目录
  - 引文格式：列表 + 一句话生成自定义格式 + 导入 .csl + 预览 + 删除
  - 剪贴板监听：可关（关掉后不读剪贴板）
  - 端口：默认 8765；改了端口 Word 插件也用「端口」按钮跟着改

十一、数据与隐私
  - 程序数据：%APPDATA%\PaperWhale（数据库、设置、日志）
  - PDF 文件：默认在「论文文件」目录（可在设置里看到实际路径）
  - 便携版数据：exe 同目录 data\
  - 只有调用大模型 / 联网补全时才发送必要文本或查询，不经过任何中转服务器
  - 卸载程序不删除数据；彻底清空请手动删除上面的目录

十二、卸载
  开始菜单 → 卸载 Nexus Paper Library，或 设置 → 应用 → 已安装的应用 → Nexus Paper Library
  卸载会同时移除 Word 的 STARTUP 模板与快捷方式；不会删你的文献库数据。
  浏览器插件需要自己在扩展页移除。

十三、常见问题
  - 双击没反应：看 %APPDATA%\PaperWhale\paperwhale.log
  - 端口被占用：程序会自动换端口；Word 里点「端口」按钮改成实际端口再点「测试连接」
  - Word 里没有 NPL 标签：确认 STARTUP 目录有 PaperWhaleMacros.dotm，重启 Word
  - Word 提示「编译错误：子过程或函数未定义」：关掉报错窗口 → 那个文档不保存关闭 →
    重启 Word；仍出现就重装一次 NPL
  - 点「插入引文」没弹窗口：确认默认浏览器可用、NPL 正在运行；
    Word 会等待 240 秒，按 Esc 可取消
  - 扫描版 PDF：没有文字层时选词、搜索和正文精读受限，可先用外部 OCR
  - 出版社下载失败：多半是限流 / 登录 / 人工验证，按提示手动过验证或稍后重试
  - 杀毒软件误报：PyInstaller 打包的程序偶尔会被误报，可加入信任
  - 版本更新内容：程序目录 docs\版本更新.md
