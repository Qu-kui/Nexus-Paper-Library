# 笔记迁移与查看

EndNote 和 Zotero 迁移时，程序会把导出文件中能关联到论文的笔记一起保存。文献已存在时，也可以重新导入带笔记的导出文件补齐。个人笔记不被覆盖；内容相同的迁移笔记不重复追加。来源笔记发生修改时保留为另一条内容，不覆盖旧版本。

## 导出方式

- **EndNote**：导出 XML，并保留 `.Data/PDF` 附件目录。读取 `Notes` 和 `Research Notes` 两类字段；摘要单独保存，不当作笔记。
- **Zotero**：优先导出 Zotero RDF，勾选「导出笔记」和「导出文件」，导入整个导出文件夹。读取通过 RDF 关系挂在论文上的子笔记，以及关联附件的文字备注。没有关联论文的独立笔记不会被猜测归属，也不会变成假论文；导入结果提示未关联数量，请在 Zotero 中挂到对应论文后重导。
- **CSV**：读取 Notes / Note / 笔记 / Research Notes 列；Extra 和 Abstract Note 分别作额外元数据、摘要处理，不当作笔记。
- **RIS**：读取 N1 备注字段；BibTeX 读取 note 与 annote/annotation 字段。格式本身未导出的笔记无法恢复。

Zotero 新建文献条目仍需匹配真实 PDF；为已经在库里的文献补导笔记不要求导出中再次包含 PDF。EndNote 的「没有 PDF 的条目也导入」选项保持原行为。

Zotero 官方建议 RDF 携带文件与笔记用于完整转移，详见[导出说明](https://www.zotero.org/support/kb/exporting)。

## 查看与追加

- 文献库点击论文，在右侧详情的「论文笔记」查看。
- 打开论文阅读器，切到「笔记」标签。原有「批注」标签继续显示程序内的定位高亮与批注。
- 「我的笔记」显示此前保存的个人笔记和 AI 回答；下面按来源显示迁移笔记，可展开收起。
- 在「追加笔记」填写想法并保存，追加到个人笔记；导入的原笔记只读。草稿在本次运行中按论文分别暂存，切换论文不会串入其他论文，关闭程序前请保存。
- 导入结果显示保留的笔记数、为已有论文补入的篇数及跳过的相同笔记数。备份、删除至回收站、恢复均包含迁移笔记；旧版本备份可继续恢复。

## 保留范围

保留文字、段落、标题、粗体、斜体、列表与普通网页链接，并以 Markdown 展示。复杂表格转为文本行；笔记图片显示「图片未迁移」提示，不下载图片或执行原 HTML。单条笔记超过100万字符会明确报错，不静默截断。

本次不把原软件数据库里的 PDF 高亮坐标迁成程序内可编辑的定位批注，也不保证复制 PDF 就带出这些标注。需要迁移 Zotero 批注文字时，先在 Zotero 中对论文使用「从批注添加笔记」，然后随 RDF 导出。操作见[Zotero PDF 阅读器文档](https://www.zotero.org/support/pdf_reader#adding_annotations_to_notes)。生成的笔记文字可以读取，原 Zotero 页码跳转链接与高亮坐标不转成 NPL 定位。

此前迁移遗漏的笔记无法从缺失内容的导出文件自动重建；请从原文献库重新导出后补导。迁移前保留原库与原导出文件。
