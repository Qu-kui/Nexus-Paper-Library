# Nexus Paper Library (NPL)

本地优先的 AI 文献工作台。文献、全文、批注、笔记都存在本机；AI 调用只发送必要片段，没有云账号，没有强制上传。

- 库：SQLite（`%APPDATA%\PaperWhale\paperwhale.db`）+ 本地 PDF 文件树（`论文文件/<大类>/<子类>/<paper_id>.pdf`）
- 检索：FTS5 全文检索（正文按页切块、1800 字/块、重叠 200 字），问答带页码引用
- 平台：Windows 桌面（Python + pywebview + FastAPI），另有 Edge / Chrome 浏览器 Connector

## 安装

**安装包**：[NPL-2.24.16-Setup.exe](release/NPL-2.24.16-Setup.exe)（GitHub 下载，58.4 MB）；也可以双击本地 `release\NPL-<版本>-Setup.exe`，按向导选择安装目录；如果 NPL 正在运行，安装器会自动识别并关掉它再继续。装完自动启动，桌面和开始菜单都有快捷方式。

**便携版**：解压 `release\NPL-<版本>-win-x64-portable.zip`，双击 `PaperWhale.exe`（数据放在 exe 同目录 `data/`）。

**升级**：直接运行新版安装包即可，会覆盖程序文件，文献库和 PDF 保持不动。

为兼容已有安装和文献库，程序文件仍名为 `PaperWhale.exe`，数据目录、数据库文件和 Word 模板文件名沿用原名；桌面、开始菜单和应用界面显示 Nexus Paper Library（NPL）。

## 主要功能

- **文献库**：拖入 PDF、导入 Zotero / EndNote / Obsidian、按 DOI / arXiv 一句入库；导入后自动去 arXiv / 开放获取源补齐缺失的 PDF（右下角实时进度条）
- **卷期页**：DOI 导入、网页保存、EndNote / RIS / BibTeX / Zotero 导入都会带上卷、期、页码；老条目可在 设置 → 数据与存储 →「补齐卷期页」按 DOI 批量补（只补空值），编辑弹窗里也能手动填
- **AI 精读**：一键生成结构化摘要（一句话结论 / 研究问题 / 方法 / 关键结果 / 局限）、要点、标签，并按 PDF 原文校正标题作者等基础信息
- **分类助手**：聊几句偏好在全库自动分类；支持「只整理未分类」和「对所有论文重新分类」；批次进度进任务中心，关窗口不停、重启续跑、失败项可重试
- **方法 / 参数**：从论文「方法」章抽实验条件、器件与材料参数，全库批量提取，跨论文按关键词查（例如「1550」看别人用什么探测器）
- **复习卡片**：把论文提炼成「可迁移知识卡」（原理、取舍、适用边界、坑），按遗忘曲线安排复习；重新生成只替换 AI 卡，手写卡保留
- **知识库问答**：基于全文检索的跨论文提问，回答标注页码来源
- **发现论文**：接收 Google Scholar 邮件提醒；也可以让 AI 围绕研究问题检索候选论文，勾选后入库
- **参考文献格式**：内置 APA / MLA / Chicago / IEEE / Nature / GB/T 7714；也可以自定义——用一句话描述（「只要前三个作者，多了写 et al.，期刊名斜体」）让 AI 编译成规则，或导入 Zotero / CSL 的 `.csl` 文件
- **参考文献外扩**：文献库右键「参考文献 / 被引…」，以一篇论文为种子拉出它引用 / 被引的文献，勾选入库
- **剪贴板监听**：复制 DOI / arXiv 链接或像论文题目的文字，窗口左下角问是否入库
- **任务中心**：PDF 抓取、批量精读、分类整理、方法参数、复习卡片等批次统一展示进度与失败原因

## 浏览器插件（NPL Connector）

- 安装包内 `browser-extension/`，Chrome / Edge 开发者模式「加载已解压的扩展程序」
- 网页一键把标题、作者、年份、期刊、DOI、摘要抓进 NPL，并尝试抓取 PDF
- 支持 Google Scholar 搜索结果页批量入库；抓不到 PDF 时自动监听页面下载，抓到后自动入库
- 只连 `127.0.0.1`，不向任何外部服务器发送数据

## Word 插件

- 在 Word 里像 Zotero 一样插入引文与文末参考文献：功能区会多一个「NPL」标签（插入引文 / 插入·更新参考文献 / 刷新 / 引文格式 / 端口 / 测试连接 / 使用说明）
- 安装包在检测到 Word 时自动复制模板到 `%APPDATA%\Microsoft\Word\STARTUP`；没装上可在「设置 → 浏览器 / Word 插件」点「安装到 Word」，然后重启 Word
- 插入引文：先在文档里选中一段文字可直接用它检索；输入序号插入，多个用逗号（例如 `2,5`）
- 参考文献：第一次放到文末，之后点「插入 / 更新参考文献」或「刷新」都会原地更新，不会重复追加
- 引文格式：APA / MLA / Chicago / IEEE / Nature / GB/T 7714；数字型格式按引文在文档中的出现顺序编号
- 自定义格式：设置 →「引文格式」里用一句话描述让 AI 编译成规则，或导入 Zotero / CSL 的 `.csl` 文件；自定义格式会出现在 Word 插件的「引文格式」列表里
- 卷期页：抓取时自动带上（Crossref / 网页 meta / EndNote / RIS / BibTeX / Zotero）；六种内置格式和自定义格式都会渲染（如 `12(3): 45–67`）
- 只连 `127.0.0.1`（默认端口 8765，插件会先探测再保存），不向外部服务器发送数据；引文以书签保存，不要手动删掉引文文字

## 导入已有文献库

- **Zotero**：文件 → 导出文库 → 选 CSV / BibTeX / RIS / Zotero RDF（勾选「导出文件」可带 PDF），在「导入」页上传；或直接选整个导出文件夹
- **EndNote**：File → Export → 格式选 XML、勾选导出附件，选导出的 `.xml`（或库所在文件夹）
- **本地 PDF 文件夹**：导入页「导入 PDF 文件夹」，会递归扫描；标题 / DOI 对得上已有论文就补全文，对不上就用 PDF 内容新建条目

## 数据与隐私

- 文献元数据、全文索引、批注、问答记录都在本机 SQLite；PDF 在本地目录
- 大模型请求由你配置的 OpenAI 兼容接口（DeepSeek、OpenAI、通义、Kimi、SiliconFlow、Ollama…）处理，只发送必要文本片段
- 卸载程序不会删除你的文献库和 PDF；备份入口在 设置 → 数据与存储（元数据备份，不含 PDF 与密钥）

## 版本规则

正式版本使用「主版本号.次版本号.补丁号」：修复和小幅优化增加补丁号；新增完整功能增加次版本号并将补丁号归零；重大且不兼容的改版增加主版本号并将其余归零。内部测试、重复打包用单独构建编号区分，不因打包次数增加正式版本号。同一版本交付前的修正合并到该版本。

## 开发

```powershell
# 安装依赖
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
# 起服务（开发）
.\.venv\Scripts\python.exe -m uvicorn paperwhale_server.main:app --port 8765
# 测试
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
# 打包（产物在 release\）
powershell -ExecutionPolicy Bypass -File build.ps1 -Version 2.10.1
```

- `web/`：前端（原生 JS 模块 + CSS）

### 术语复习与单词本

术语选择题有 2–6 个选项，按两个方向分别安排间隔。练习进度取双方向较低值，并非记忆概率；双向达到 100 才标记「熟识」，每个满分方向 7 天后仍会维护复习。普通答对按该方向连续确定答对次数增加 60 / 25 / 15 / 5 分；模糊答对仅获 30% 积分、最高 99 分，不累计确定答对连胜。答错或不认识扣该方向 45 分，5 分钟后再练。初始排期是产品启发式，非普遍最优的记忆曲线。

复习默认手动下一题，可选保存后 4 秒自动推进。保存失败保留本题，可重试；跳过会提示保存状态未确认。词条列表支持分页、搜索、编辑释义／类型／音标／词性／英文别名。无释义的缩写只以「全称 → 缩写」出题，补充释义后可练双方向。同形异义词按类型、释义和全称区分；旧重复行及历史均保留，不自动合并。迁移保留旧答题总次数；已被旧版截断的历史无法恢复，无法还原结果的次数显示为「旧记录结果未知」。旧版不带题目 ID 的答题接口继续兼容；新版界面使用带有效期、后端判分和去重的题目接口。

SQLite 是权威数据。单词本 JSON / CSV 是可再生成的导出快照，手动修改不会导入；答题导出在后台合并写入，打开单词本会立即重新导出。manifest.json 最后发布，记录生成版本与文件 SHA-256；其 files 指向两组轮换快照中的完整一组，导出中断时仍可读取上一组。words.json / words.csv 是兼容入口，需强一致读取时请按清单的 files 路径和校验值读取，遇到版本变化可重试。CSV 包含全部来源、别名和不再复习状态。程序中的显式删除会影响下一次快照；「不再复习」仅停用出题并保留词条。
